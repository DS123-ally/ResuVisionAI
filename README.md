ResuVision AI is a premium resume analysis platform that helps job seekers optimize their resumes using AI-driven insights.

## 🚀 Live Demo
**Frontend**: [https://resuvision-frontend-a4xpqc773a-uc.a.run.app](https://resuvision-frontend-a4xpqc773a-uc.a.run.app)  
**API Status**: [https://resuvision-backend-a4xpqc773a-uc.a.run.app/](https://resuvision-backend-a4xpqc773a-uc.a.run.app/)

## ✨ Features
- **AI Resume Analysis**: Instant feedback on resume content and structure.
- **ATS Scoring**: Calculate your match against job descriptions.
- **AI Career Advisor**: Chat with an AI to get personalized career advice.
- **Premium UI**: Modern, glassmorphic design with smooth animations.

## 🛠️ Technology Stack
- **Frontend**: Next.js (Standalone Mode), Tailwind CSS, Framer Motion.
- **Backend**: FastAPI (Python), Groq AI (Llama 3).
- **Deployment**: Google Cloud Run (Containerized).

## 📂 Project Structure
- `frontend/`: Next.js application.
- `backend/`: FastAPI service.
